# Archive

This folder holds documentation and records that have been superseded or are
otherwise no longer relevant to how the project currently works — think retired
plans, old write-ups, and other artifacts kept for historical reference rather
than active use.

**Nothing in this folder describes the current state of the project.** Content
here reflects decisions, plans, or conditions that applied at some point in the
past and have since changed. Do not read anything under `docs/archive/` as
instructions, specifications, or facts about how the project works today.

Contributors and coding agents: treat everything in this folder as historical
context only. If you're trying to understand the current codebase or figure out
how to make a change, look elsewhere first (the root `README.md`, `CLAUDE.md`,
`AGENTS.md`, `docs/`) — never use an archived file to justify or guide new work.
